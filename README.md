# embed-services-dashboard
EMBED Services Dashboard
Dashboard for EMBED based Arcade Locations. In partner with Zach Tristan and myself, Mike Adams. We are creating this to make it easier for troubleshooting and notification of issues as they happen rather than long after. 

Packaged EXE self-updates require a GitHub Release tagged to match `version.json`'s `releaseTag` and containing the executable named by `exeAsset`. The release asset's SHA-256 digest must be available from GitHub release metadata, or be set as `exeSha256` in `version.json`. Users already running an older EXE must replace it manually once with a build containing the EXE updater; subsequent releases can install through the dashboard.

To bootstrap WinRM on a target that does not have it configured, open Remote Admin, select **WMI / DCOM**, and use **Enable WinRM (WMI)**. WMI/DCOM and RPC firewall access must already work, and the action requires target administrator credentials. It runs the fixed `winrm quickconfig -force` command, which enables the HTTP listener (normally port 5985) and configures the target firewall; review local firewall policy afterward.

The SQL tab's **Backup + Shrink Log** action runs the confirmed ECS7 log backup, shrink, and file-growth update sequence. Settings lets you configure the SQL logical log file name (for example, `ECS7_Seabrook_Log`), shrink target, file-growth increment, backup directory, and maximum age of the last full backup. A full backup must have completed within that age limit before maintenance can run. The backup filename remains `ECS7_Log.trn`. The configured directory is on the SQL Server host, and the SQL Server service account needs write access. Reusing the path appends another backup set to the `.trn` file. The action requires the database to be online and use FULL or BULK_LOGGED recovery, plus SQL permissions for log backup, `DBCC SHRINKFILE`, and `ALTER DATABASE`. Shrinking is best effort; active log contents can prevent SQL Server from reaching the configured target, and the dashboard reports the actual resulting size.

The Logs tab scans `C:\Program Files (x86)\ECS7\Logs` for text logs and separates them into ECSGenService, EMBED API, ECS Reports, GURU Server, KIOSK Service, KIOSK, SALES, POS, PRIZES, EPG, and Other subtabs using file and folder names. KIOSK Service logs are distinguished by service-related names; other KIOSK logs have their own tab. EPG credit card transaction logs have their own tab. Select a file to view its latest 5,000 lines; severity and detected timestamp filters can narrow the view to errors, warnings, or recent entries, and Find Next searches the displayed lines.
